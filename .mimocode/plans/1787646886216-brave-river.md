## Co działa dobrze (mocne strony)

- SCRAM-SHA-512 (przewyższa epic5, dorównuje epic6)
- 82 moduły LiCe5 załadowane
- SQLCipher AES-256 (przewyższa oba)
- 7 themes, 102 komendy Lua, 50+ funkcji API
- Multi-server, split screen, message breaking
- DCC SEND receive działa end-to-end
- 20+ subkomend /window

## Pliki do modyfikacji

- `src/commands/registry.rs` — nowe komendy, naprawa stubów
- `src/scripting/api.rs` — nowe funkcje Lua
- `src/irc/proto.rs` — IRC protocol handlers
- `src/irc/connection.rs` — CAP/SASL/STARTTLS
- `src/ui/renderer.rs` — UI features
- `src/ui/input.rs` — key bindings, mouse
- `src/app.rs` — data structures
- `src/main.rs` — auto-save tick, mouse events
- `src/storage.rs` — persistence
- `modules/*.lua` — LiCe5 module improvements
- `DOCS.md` — dokumentacja

## Weryfikacja

Po każdym priorytecie:
1. `cargo build --release` — zero warningów
2. `cargo test --test lua_integration -- --nocapture` — wszystkie testy przechodzą
3. Test na irc.spadhausen.com — komendy działają w praktyce
4. `git commit && git push` — zmiany w repo
